# Setup Instructions

## Note that this repo is a work in progress (pooling in resources from multiple sources to create a test project). Will be updated as needed 🤷‍♂️
- Download/clone repo, and use yarn/npm install to set up the project
- Create and configure a .env file in the project folder with apt varaibles for Thirdweb and Supabase for the project
- Use yarn/npm to run the project using vite.
